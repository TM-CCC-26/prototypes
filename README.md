# Prototypes

A password-protected landing page for internal design prototypes. `index.html`
contains only AES-256-GCM ciphertext — none of the prototypes are in this
repository in readable form.

Ask whoever sent you the link for the passphrase. After unlocking, you'll see
a chooser for which prototype to test.

These are design mock-ups used to test ideas. They are not a real service,
not connected to anything, and do not reflect an agreed decision.
